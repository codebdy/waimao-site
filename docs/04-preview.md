# 预览和修改

[← 返回首页](../README.md) · 上一步：[确定网站风格](03-style.md) · 下一步：[上传到 GitHub](05-github.md)

**这篇适合：** AI 已经生成了网站，想在自己电脑上先看看效果的人。

## 在电脑上打开网站

1. 打开 `my-waimao-site/website` 文件夹，确认里面有 `package.json`。
2. 在这个文件夹的地址栏输入 `powershell` 回车，打开一个终端窗口。Mac 用户：在访达里右键 `website` 文件夹，选“服务 → 新建位于文件夹位置的终端窗口”。
3. **第一次**预览时输入下面的命令，等它跑完（几分钟）：
   ```text
   npm ci
   ```
4. 输入下面的命令启动预览：
   ```text
   npm run dev
   ```
5. 窗口里会出现一个网址，一般是 `http://localhost:4321`，复制到浏览器打开，就能看到你的网站了。做了多语言的话，点页头的语言切换按钮，或在网址后面加 `/de/` 这样的语言代码，查看其他语言版本。
6. 看完后，回到这个窗口按 `Ctrl + C` 停止。

> 用了站内询盘表单的话：本地预览只能看表单外观，**真实提交要在发布后的网站上测试**。

> **Windows 提示“禁止运行脚本”？** 把命令里的 `npm` 换成 `npm.cmd`，比如 `npm.cmd ci`、`npm.cmd run dev`。

**注意：**
- 这个网址**只有你自己的电脑能打开**，不是上线的网址，发给客户是打不开的。
- 预览时窗口要一直开着，关了网站就打不开了。
- AI 不会自己替你启动预览，这一步由你来做。也可以直接让 AI 帮你启动。

## 告诉 AI 要改什么

看网站时发现问题，直接告诉 AI，**说清楚哪一页、哪个位置、改成什么**：

```text
首页第一屏的标题改成 "Reliable Industrial Pumps from China"。
产品页的离心泵图片换成 my-waimao-site/资料/pump-1.jpg。
联系页加上 WhatsApp：+86 138xxxx。
```

AI 改完后，刷新浏览器就能看到变化（预览没关的话会自动更新）。

## 上线前一定要自己检查

- [ ] 公司名称、地址、电话、邮箱都正确
- [ ] 所有示例产品和演示文字都换成了真实内容（页面底部的 “Demonstration website” 提示会在开启 Google 收录后自动消失，见 [SEO](seo.md)）
- [ ] 产品参数、认证、产能都是真的（AI 不知道你公司的真实情况，可能写错）
- [ ] 图片都是自己有权使用的
- [ ] 用手机打开看一遍（手机和电脑连同一个 WiFi 时，也可以让 AI 告诉你怎么在手机上预览）
- [ ] 隐私页的内容已经按你公司实际情况补充

最后让 AI 跑一遍检查：对它说“发布前帮我做一下检查”。
