# AI 工作说明（本网站）

本网站由 waimao-site skill 制作，是 Astro + Tailwind 外贸网站。任何 AI 工具修改本网站前：

1. 先读 `brief/requirements.md`（客户的长期要求）和 `brief/image-prompts.md`（本网站的图片风格与提示词），按其中要求执行。
2. 客户提出长期要求或反馈时（例如文案语气、产品展示方式、图片偏好、禁止事项），更新上述文件的对应部分和反馈记录，并告诉客户“已记住”；一次性的文字修改不用记。图片例外：每张图最终使用的提示词都写进 `brief/image-prompts.md` 的图片清单，客户对图片的每次修正都先记进去再重新生成。
3. 能使用 waimao-site skill 时按 skill 的规则工作；不编造产品参数、认证、产能、客户案例或照片。
4. 每次修改完成或客户要看网站时，由 AI 直接启动本地预览（`npm.cmd run dev` / `npm run dev`，首次先安装依赖），预览要在回复结束后继续运行，把实际网址发给客户；不要只给客户一段命令让他自己运行。
