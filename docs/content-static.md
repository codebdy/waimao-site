# 纯静态站（默认）

[← 返回首页](../README.md) · 其他方式：[RXCMS 站](content-rxcms.md) · [WordPress 站](content-wordpress.md)

**这篇适合：** 刚开始做外贸网站、产品不经常变动的人。**不知道选什么就选这个。**

## 它是什么

网站的文字、产品资料都存在网站文件夹里。要改内容时，告诉 AI 改哪里，它直接改文件，你再重新发布。

不需要后台账号，不需要任何密钥，也不需要额外付费的内容管理系统。

## 优点和不足

| 优点 | 不足 |
| --- | --- |
| 最简单，不用注册任何后台 | 改内容要通过 AI，再发布一次 |
| 网站打开快、稳定、安全 | 不能自己登录后台改 |
| 托管费用低 | 默认没有站内询盘表单（只有邮件链接） |

## 内容存在哪

在网站文件夹（以公司英文名命名，如 `huali-pumps`）里。你**不需要自己去找文件**，直接跟 AI 说：

```text
新增一款产品：型号 XP-200，参数和图片在 资料/XP-200 文件夹里。
把 About 页面的成立年份改成 2008 年。
删掉产品 "Sample industrial component"。
```

改完按[日常更新](08-update.md)的流程发布。

想了解文件放在哪，大致是这样（都在网站文件夹里）：

| 内容 | 位置 |
| --- | --- |
| 产品 | `src/content/products/en/产品名.md`，每个产品一个文件（`en` 是语言，德语就在 `de` 文件夹） |
| 文章 | `src/content/articles/en/文章名.md`，每篇文章一个文件；某种语言有了文章，那种语言的网站就会自动出现文章栏目 |
| 图片、小图标 | `src/assets/` 文件夹；AI 把图片用到页面上后，照片会在生成网站时自动压缩成适合网页的格式，SVG 小图标保持原样 |

这些 `.md` 文件可以用记事本打开，开头是产品名、参数、图片等资料，下面是正文。你也可以自己改文字，但改完最好让 AI 检查一遍，格式写错网站会生成失败。

> 生成网站时，日志里可能出现一条黄色提示 “The collection "articles" does not exist or is empty”，意思是还没有文章，不影响网站，可以忽略。

**多语言网站**也是这样改：告诉 AI “给 XP-200 加上德语版”。某个产品还没有某种语言的版本时，那种语言的网站就暂时不显示它。详见[开始建站](02-start.md#要做几种语言)。

## 客户怎么联系你

默认是**邮件链接**：客户点联系页的按钮，会打开他电脑上的邮件软件给你写信。告诉 AI 你的询盘邮箱即可。

想让客户直接在网站上填表单提交，需要开通 RXCMS 询盘服务，见[询盘表单](inquiry.md)。纯静态站也可以单独加上表单，不用换成 RXCMS 站。

## 以后可以换吗

可以。产品越来越多、想自己登录后台管理时，告诉 AI “换成 RXCMS 站”，现有页面和设计都能保留（多语言网站换成 RXCMS 时，需要作者协助接入）。
