# 常见问题

[← 返回首页](../README.md)

按类别排列，找到你遇到的情况就行。没找到的问题，把现象和错误文字发给 AI（先遮住密码、密钥）。

## 安装和使用

**AI 找不到这个 skill？**
多半是文件夹放错了位置或多套了一层。对照[安装](01-install.md)里的表格检查，打开 `export-site` 文件夹要能直接看到 `SKILL.md`。实在不行，直接对 AI 说“请先读取 export-site/SKILL.md，按里面的说明帮我建站”。

**DeepSeek 网页版 / App 能用吗？**
不能。它们只能聊天，不能读写你电脑上的文件。要在支持 skill 的工具里把模型选成 DeepSeek。

**Windows 输入 npm 提示“禁止运行脚本”？**
把命令里的 `npm` 换成 `npm.cmd`，比如 `npm.cmd ci`、`npm.cmd run dev`。或者在文件夹地址栏输入 `cmd` 回车，在打开的黑色窗口里执行。

**Mac 上找不到 `.claude` 这类文件夹？**
以点开头的文件夹默认隐藏，在访达里按 `Command + Shift + .` 显示出来。

**出错了怎么问 AI 最有效？**
把**完整的错误文字**复制给它，说清楚你刚才在做哪一步。不要只说“出错了”或“不行”。

## 外观和品牌

**浏览器标签上的小图标（favicon）怎么换？**
把 Logo 发给 AI，说“把网站小图标换成这个 Logo”。最好给正方形、512×512 以上的 PNG 或 SVG 图片。换完看不到变化，是浏览器缓存，用无痕窗口打开就能看到。

**链接发到微信、WhatsApp、LinkedIn 没有预览图？**
默认没有分享图。准备一张 1200×630 的横图（产品或工厂照片都行），对 AI 说“把这张图设成分享图”。

**网站的颜色、字体、布局能改吗？**
都能改。看[确定网站风格](03-style.md)，说得越具体越好。

**手机上效果怎么样？**
网站会自动适应手机屏幕，但一定要用手机实际打开看一遍。有问题截图发给 AI。

## 内容

**示例产品和演示文字怎么删？**
告诉 AI 换成你的真实产品和公司介绍。上线前逐页检查一遍。

**AI 写的认证、产能、出口国家能直接用吗？**
**不能直接用。** AI 不知道你公司的真实情况，这些必须你自己核对。没有的认证不要写，外贸采购商会核实，写错了很伤信任。

**网上找的图片能用吗？**
不要随便用，可能侵权，被投诉后网站可能被下架。用自己拍的照片，或者有正版授权的图片。

**能做多语言网站吗？**
能。告诉 AI 要做哪几种语言（比如英语、德语、西班牙语），每种语言会有独立网址，Google 能分别收录。译文最好由懂这门语言的人核对，尤其是产品参数和专业术语。用 WordPress 后台管理内容时，多语言取决于你的 WordPress 是否装了多语言插件。

## 发布和域名

**网站做好了，客户怎么看不到？**
在电脑上预览的网址（`localhost`）只有你自己能打开。要按[上传到 GitHub](05-github.md)和 [Vercel](06-vercel.md) / [Cloudflare](07-cloudflare.md) 发布后，别人才能访问。

**关掉电脑，网站还在吗？**
发布到网上的网站一直在，和你的电脑无关。本地预览关了就没了。

**一定要买域名吗？**
不一定。先用平台送的免费网址，满意了再买。正式做生意建议用自己的 .com 域名，客户更信任。见[注册域名并绑定](09-domain.md)。

**绑定域名后公司邮箱收不到邮件了？**
多半是改 DNS 时删掉或覆盖了邮箱的 MX 记录。马上联系域名商或邮箱服务商恢复，以后改 DNS 只加网站需要的记录。

**HTTPS（地址栏的小锁头）要自己买证书吗？**
不用，Vercel 和 Cloudflare 自动配置，免费。

**改了内容，网站没变？**
依次检查：GitHub Desktop 里有没有点 **Push**（只 Commit 不算）；平台这次部署有没有成功；浏览器按 `Ctrl + F5` 强制刷新。

**要不要 ICP 备案？在国内打开慢怎么办？**
不需要备案，备案只针对服务器在中国大陆的网站。Vercel 和 Cloudflare 在国内打开可能偏慢，但外贸网站主要给海外客户看，影响不大。自己在国内检查时慢一点是正常的。

**要花多少钱？**
- skill：免费
- AI 工具：按工具自己的收费
- 域名：每年几十到一百多元（.com）
- 托管：Vercel 的免费版只限个人非商业用途，公司网站要用付费 Pro；Cloudflare Pages 有免费额度
- RXCMS 平台、外贸 SEO 代运营：需要时联系作者

## Google 搜索

**为什么 Google 搜不到我的网站？**
1. 网站默认**不允许收录**（防止示例内容被收录），要让 AI 打开，见 [SEO](seo.md)
2. 到 Google Search Console 提交网站地图
3. 新网站被收录一般要几天到几周，排名更慢，需要持续发布真实、详细的内容

**想知道有多少人访问网站？**
接上 Google Analytics，见 [Cookie 同意框和 Google 统计](cookie.md)。

## 询盘和邮件

**客户怎么联系我？**
默认是邮件链接，点击会打开客户自己的邮件软件。想要网页上直接填表提交，见[询盘表单](inquiry.md)。

**表单显示“已收到”，我却没收到邮件？**
“已收到”表示询盘已经保存在后台，不代表邮件一定送达。先登录后台看询盘记录，再查邮箱的垃圾邮件箱。

**网站会送公司邮箱吗？**
不会。`sales@你的域名.com` 这样的企业邮箱要另外开通（比如腾讯企业邮、阿里邮箱、Google Workspace），开通时注意别和网站的 DNS 记录冲突。

**会收到很多垃圾询盘吗？**
站内表单自带隐藏陷阱和人机验证，能挡住大部分机器人。邮件链接方式下，你的邮箱地址公开在网页上，可能收到一些推销邮件，属于正常现象。

## 安全和账号

**不小心把密码或密钥发进了聊天里怎么办？**
马上到对应后台把它**作废**，重新生成一个新的。不要接着用旧的。

**GitHub 上的代码别人能看到吗？**
上传时勾选了 **Keep this code private** 就看不到。代码私有不影响网站正常被访问。

**换电脑了怎么办？**
代码都在 GitHub 上。见[日常更新](08-update.md#换了电脑怎么办)。

**各种账号密码怎么管？**
GitHub、Vercel / Cloudflare、域名商、Google 账号都很重要，建议用公司邮箱注册，开启双重验证，密码记在安全的地方。员工离职时检查这些账号的权限。
