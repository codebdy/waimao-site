# B2B 外贸网站页面蓝图

新建站或新增页面时阅读。每类页面写清：采购商来这页要解决什么、模块顺序、需要用户提供的资料、SEO 与转化要点。模块是可选清单，不是每页都要齐全；资料缺失时保留结构并列出待补项，**不编造**参数、认证、产能、客户、评价、照片或联系方式。

改编自 Marketing Skills 的 copywriting、site-architecture、cro 与 Claude SEO 的 seo-page、seo-schema 方法，按外贸采购场景重写；出处见 [第三方声明](../THIRD_PARTY_NOTICES.md)。具体 SEO 标准见 [seo](seo.md)，设计见 [design](design.md)，规划见 [planning](planning.md)。

## 全站结构与导航

- 层级尽量扁平：首页 → 栏目（产品、OEM/定制、关于、文章、联系）→ 详情。重要页面距首页不超过 3 次点击；某个下拉菜单超过约 20 项再加一层分类。
- 页头：Logo 在左并链接首页；主导航 4–7 项，按采购商关心程度排序；最右放主行动按钮（如 “Get a Quote”，对应已实现的询盘入口）。多语言时语言切换放页头右侧。
- 页脚按列分组：产品分类、公司（关于、工厂/质量、OEM）、资源（文章、下载）、联系与法律（联系方式、隐私政策）。只放真实存在的页面。
- 面包屑：详情页显示“首页 › 栏目 › 当前页”，与网址路径和 BreadcrumbList 结构化数据一致；当前页不加链接。
- 网址：小写、连字符分隔、用有意义的英文 slug 而不是 ID，路径反映层级（`/products/{category}/{product}/` 或 `/products/{product}/`，全站统一一种）；末尾斜杠策略全站一致；不在网址里放日期或查询参数。网址永久迁移或有对应替代页时安排 301 跳转；删除且没有替代页时返回 404/410。
- 内部链接：每页至少有一个站内入链，没有孤立页面；锚文字描述目标（如 “stainless centrifugal pumps”），不用 “click here”；重点产品和询盘页得到更多链接；产品页互链相关产品，文章链回相关产品页。

## 本地内容与图片落地

- 默认 local 站的产品和文章分别放在 `src/content/products/<语言>/`、`src/content/articles/<语言>/`，每条内容每个语言一个 `.md` 文件，frontmatter 由 `src/content.config.ts` 校验，正文写 Markdown。共享 key 关联译文，slug 可独立；不要复制默认语言正文冒充译文。
- 产品图、文章图、Logo、页面插图和小图标统一放 `src/assets/`，可按 products、articles、brand、icons 分类。集合里的图片字段用 `image()` 校验，frontmatter 的 images 为 `[{ src: 相对于该 Markdown 的路径, alt: 对应语言的图片说明 }]`。未提供图片可省略 images；一旦提供，alt 必填。装饰用途应在具体页面单独明确，不拿空 alt 代替产品说明。
- 页面用 `astro:assets` 的 `<Image>` 或 `<Picture>`；当前模板产品卡片、产品和文章详情使用 `<Image>`，栅格图输出 WebP、多尺寸 srcset/sizes 和实际宽高。不复制原始 PNG/JPEG 到 public 绕过优化。正文用来写文字，内容图片集中在 frontmatter 管理，不用原始 HTML `<img>` 绕过这条管线。
- 首屏主图 `loading="eager"`、`fetchpriority="high"`，其他图片 lazy；不要把所有图片都标 high。按页面实际显示宽度提供多尺寸，源图小于目标宽度时不放大；保留长宽比。
- 当前页头是文字公司名，没有虚构 Logo。客户提供真实 Logo 或小型 SVG 图标时从 assets 导入并用图片组件，保留 SVG 矢量。大型 SVG 插图和背景放 public，按路径引用，不做栅格优化；固定网址的 `public/favicon.svg` 和 public 下的 ogImage 是另外两个例外。
- RXCMS / WordPress 远程图片继续走原有媒体映射/HTML 清理，不转成本地内容或改成新的抓取流程。添加自定义页面的图片字段时复用集合的 image() 校验与相同组件规则。

## 文案通用规则（英文及其他语言）

- **具体胜过空话**：写型号、材质、规格范围、适用工况、包装方式、交期区间等可核实信息；不用 “high quality / best / leading / one-stop” 这类人人都能说的词。
- **三问检查**每个标题和卖点：采购商能想象出来吗？能被证实或证伪吗？竞争对手能原样照抄吗？第三问答“能”就重写。
- **讲买家得到的结果**，再给支撑它的特性：例如 “Reduce downtime with sealed bearings rated for 20,000 h” 优于 “Advanced bearing technology”（数字必须来自用户资料）。
- **无法证实的说法**：指出缺什么证据（认证文件、检测报告、客户授权），先用可证实的替代表述，并把证据列入待补清单。
- **避免 AI 腔**：不用 “In today's fast-paced world / Unlock the power of / seamless / robust / cutting-edge”；少用 “not X, but Y” 对比、成串否定（no setup, no waiting）、自问自答和感叹号；单句尽量不超过 20 词；保留客户自己的行业用语。
- **CTA 文案**：动词 + 得到什么，如 “Request a Quote”“Get the Datasheet”“Send Your Drawing”；不用 “Submit / Learn More / Click Here”。按钮必须对应已实现的动作。
- 多语言版本按目标市场的术语、单位和习惯写，不是逐字翻译；译文请用户安排懂该语言的人核对参数与术语。

## 首页

**采购商要判断**：这家供应商做什么、是否适合我、可信吗、下一步在哪。

模块顺序（按资料取舍）：
1. **首屏**：一句话讲清提供什么、给谁用（如 “Centrifugal Pumps for Water Treatment and Irrigation Projects”），一两句补充具体卖点，主按钮询价 + 次按钮看产品；配真实产品或工厂图。
2. **产品分类入口**：3–6 个主要分类，每个有图、一句用途说明、链接。
3. **为什么选我们**：3–5 条可证实的优势（工厂面积、设备、质检流程、认证、出口经验），每条带证据。
4. **应用 / 行业**：产品用在哪些场景，链到对应产品或文章。
5. **合作流程**：3–4 步（询价 → 打样/方案 → 生产质检 → 发货），降低采购商的顾虑。
6. **信任证据**：真实的认证、展会、合作客户（需授权）、工厂照片；没有就不放这一块。
7. **常见问题**：起订量、交期、付款、样品、定制等真实答案。
8. **结尾行动**：重复核心价值 + 询价按钮。

需要用户提供：公司一句话定位、主营分类、可公开的工厂/认证/出口数据、首屏图片、询盘方式。
SEO：title 用“核心产品 + 定位 | 公司名”；H1 为首屏主标题；结构化数据 Organization + WebSite + WebPage（模板已输出）。

## 产品分类页

**采购商要判断**：这一类里哪款适合我。

模块：分类简介（适用场景、选型要点 2–4 段）→ 产品卡片列表（图、型号/名称、1–2 个关键参数、链接）→ 选型指引或对比表（有资料时）→ 询价入口。
需要用户提供：分类说明、各产品关键参数。
SEO：title “分类名 + 关键属性 | 公司名”；分类页有独立介绍文字，不只是产品列表；产品多时分页，每页保留自身 canonical 和可抓取的分页链接。

## 产品详情页

**采购商要判断**：规格是否满足、能否定制、怎么询价。

模块顺序：
1. 产品名 + 一句用途；主图（多角度、细节、尺寸图），首图不懒加载。
2. **关键参数表**：用语义表格，单位统一；手机上宽表允许在提示区域内横向滚动。
3. 应用场景与选型说明。
4. 材质、工艺、质检、认证（仅真实的）。
5. 包装与运输、起订量、交期区间（用户提供才写）。
6. 定制选项（OEM/ODM 可调整的项目）。
7. 下载：规格书、说明书（有真实文件才显示）。
8. 相关产品（3–6 个）。
9. 询价按钮，询盘时自动带上产品名或来源页。

需要用户提供：完整参数、图片、应用、可选项、文件。缺参数时保留表格结构并列出待补项。
SEO：title “型号/产品名 + 关键规格 | 公司名”；H1 为产品名；结构化数据 Product（name、description、image、url），**没有公开价格就不加 Offer，没有真实评价就不加 AggregateRating/Review**；BreadcrumbList。

## 关于我们 / 工厂与质量

**采购商要判断**：是真工厂还是贸易商、规模和能力、靠不靠谱。

模块：公司故事（为什么做、做了多久、服务过什么市场）→ 工厂与设备（真实照片、面积、产线）→ 质检流程与认证（附证书图）→ 团队（可选）→ 展会与客户（需授权）→ 行动按钮（参观工厂 / 视频验厂 / 询价）。
SEO：title “About + 公司名 + 定位”；结构化数据 Organization（可补 logo、contactPoint、sameAs 社媒链接，均需真实）。

## OEM / ODM / 定制服务

**采购商要判断**：能不能按我的要求做、流程和门槛。

模块：可定制内容（尺寸、材质、颜色、Logo、包装）→ 合作流程（需求 → 图纸/打样 → 确认 → 量产 → 质检 → 发货，按真实流程）→ 起订量与周期（用户提供）→ 案例（真实且授权）→ 行动按钮（“Send Your Drawing / Requirements”）。
SEO：title “OEM/ODM + 产品类别 + Manufacturer | 公司名”；可用 Service 结构化数据（内容真实时）。

## 联系 / 询价页

**采购商要判断**：怎么最快拿到报价。

模块：一句话说明会多快回复（只写用户承诺得到的）→ 询盘表单（字段只收必要信息：姓名、邮箱、公司、需求；可选：国家、数量）或邮件链接 → 其他渠道（电话、WhatsApp，用户确认后才放）→ 地址与时区（可选）→ 隐私说明链接。
表单规则见 [询盘契约](inquiry.md) 与 [design](design.md)。结构化数据可用 ContactPage。

## 文章 / 指南

**采购商要判断**：这个问题怎么选、怎么用、要注意什么。

模块：明确回答的标题 → 开头直接给结论 → 分节展开（选型标准、对比、常见错误）→ 真实图表或照片 → 相关产品链接 → 询价入口。
作者与日期：有真实作者和发布日期才显示并写入 Article 结构化数据（headline、datePublished、author、image），不编造。
选题、关键词研究和持续内容运营不在本 skill 范围；用户需要时可说明作者提供外贸 SEO 代运营服务。

## 新建站的推荐页面组合

- **最小可上线**：首页、产品列表、产品详情、关于、联系、隐私政策。
- **常见扩展**：产品分类页、OEM/定制、工厂与质量、文章。
- 按用户资料决定，不为凑页面制造空页或只替换地名、关键词的重复页。
