# 功能一览

[← 返回首页](../README.md)

**这篇适合：** 想一次看清这个 skill 能做哪些事的人。每项功能都写了它是什么、怎么跟 AI 说、详细说明在哪篇。

所有功能都是**用中文跟 AI 说一句话**就能用，不需要懂代码。

| --- | --- | --- | --- |

## 四、SEO（站内技术 SEO 一套搞定）

建站时自动做好，不用另外请人：

| 功能 | 有什么用 |
| --- | --- |
| **标题和描述** | Google 搜索结果里显示的标题和简介，每页独立 |
| **网站地图** | 告诉 Google 网站有哪些页面 |
| **规范网址** | 避免重复内容影响排名 |
| **结构化数据** | 让 Google 看懂公司、产品、文章、面包屑路径 |
| **多语言标注** | 让各国客户在 Google 上看到对应语言的页面 |
| **收录开关** | 演示内容不被收录，资料换成真实的后一句话开启 |
| **SEO 检查** | 随时说“帮我检查一下网站的 SEO”，AI 会检查并给出修改建议 |

上线后的 Google Search Console 提交步骤，见 [SEO](seo.md)。

## 七、发布与维护

> 💰 **不用买服务器，起步零成本。** 网站发布在 Cloudflare 这样的云平台上，不需要租服务器，也不用懂服务器维护。Cloudflare 的免费版就够一个外贸网站起步使用，访问快、自带 SSL 证书（网址以 https 开头，地址栏显示小锁），面向全球访问。托管不花钱，网站本身一般只需要一个域名的钱（每年几十到一百多元），域名也可以先不买；AI 工具按各家规则收费。

| 功能 | 是什么 | 详细说明 |
| --- | --- | --- |
| **发布到 Cloudflare**（推荐） | 连接 GitHub 后自动发布，**免费版就够起步用，公司网站也可以用** | [发布到 Cloudflare](06-cloudflare.md) |
| **发布到 Vercel** | 连接 GitHub 后自动发布；免费版只限个人非商业用途，公司网站用付费版 | [发布到 Vercel](07-vercel.md) |
| **自动更新** | 改完内容推送到 GitHub，网站自动更新 | [日常更新](08-update.md) |
| **绑定自己的域名** | 用 `www.你的公司.com` 访问网站，自动配置 SSL 证书（https 加密） | [注册域名并绑定](09-domain.md) |
| **更换发布平台** | 在 Vercel 和 Cloudflare 之间切换 | [日常更新](08-update.md) |
