# 使用小技巧

[← 返回首页](../README.md)

**这篇适合：** 网站已经能做出来，想让它更漂亮、更像你的行业、更能带来询盘的人。每条技巧都附了可以直接发给 AI 的话。

## 一、怎么做出漂亮的网站

1. **先找参照，再动手。** 找 2 到 3 个你喜欢的网站截图给 AI，比用形容词描述有效得多。见[照着喜欢的网站做风格](03-style.md#看中了某个网站的风格让-ai-照着做)。
2. **颜色少而统一。** 一个主色（通常取自 Logo）加一个强调色就够了，按钮统一用强调色。
   > “全站只用我们 Logo 的深蓝做主色，询价按钮统一用橙色。”
3. **好照片胜过一切装饰。** 一张清晰的工厂全景或产品细节图，比任何图标和特效都有说服力。照片尽量统一光线和背景。
4. **留白要大方。** 内容挤在一起显得廉价。
   > “每个区块上下多留一些空白，首页只保留最重要的五块内容。”
5. **字体别超过两种**，标题醒目、正文清楚就好。
6. **用手机看一遍。** 很多海外采购商用手机浏览，手机上好看才算真的好看。
7. **AI 生成的图片要统一风格。** 让 AI 先在 `brief/image-prompts.md` 定好图片风格，再逐张生成，不然每张图像不同网站拼起来的。

8. **动效和轮播适度就好。** 想让网站更有动感，可以直接跟 AI 说，它会用成熟的动效工具来做：
   > “产品区块滚动到时淡入出现。”“首页做一个产品图片轮播。”“首页背景加一个有科技感的动画。”

   动效太多反而让人眼花、拖慢打开速度。首屏内容会保持立刻可见，访客在系统里关闭了动画时，网站也会自动减少动效。

## 二、怎么做出适合你行业的风格

先告诉 AI 你的行业和主要客户，它会按行业特点安排，你也可以参考下表：

| 行业 | 采购商最看重 | 风格建议 |
| --- | --- | --- |
| 机械、零部件、工业设备 | 参数、精度、产能、认证 | 稳重的深蓝、灰色调，参数表清晰，多放工厂和设备照片 |
| 建材、五金 | 规格、材质、项目案例 | 质感强的大图、工程案例展示，颜色朴实 |
| 家居、家具、纺织 | 款式、材质、搭配效果 | 明亮温暖，大量场景图，按系列展示 |
| 电子、电器 | 型号对比、认证、技术参数 | 简洁现代、白底为主，型号对比表 |
| 食品、农产品 | 品质、安全认证、产地 | 清新自然的配色，突出产地和检测证书 |
| 美妆、个护 | 包装、配方、定制能力 | 精致时尚，突出包装和 OEM 定制 |
| 医疗、化工 | 合规、资质、安全 | 干净专业，资质证书放显眼位置 |

> “我们是做五金工具的，主要卖给欧洲的批发商，请按这个行业的特点设计网站风格。”

这只是常见做法，不是规定，最终以你的品牌和喜好为准。

## 三、内容怎么写才适合你的行业

1. **用采购商的语言。** 写他们会搜的词，比如 “stainless steel ball valve DN50”，不要只写内部型号。
2. **参数要全、要准。** 外贸采购最看重规格，宁可列一张完整的参数表，也不要写一堆形容词。
3. **把顾虑提前回答。** 起订量、交期、付款方式、能否打样、能否贴牌，这些是采购商最常问的。
   > “在首页和产品页加上常见问题：起订量 500 件，交期 25 天，支持 OEM 贴牌，可免费寄样。”（数字换成你的真实情况）
4. **用证据代替口号。** “20 年经验”不如“2005 年建厂，3 条生产线，月产能 5 万件”，前提是真实。
5. **每页一个明确的下一步。** 产品页引导询价，文章引导看产品，不要让采购商看完不知道该做什么。
6. **翻译请懂行的人核对**，尤其是专业术语和单位，机器翻译的错误会让人觉得不专业。

## 四、其他实用技巧

- **先做最小可用版本：** 首页、产品、关于、联系四类页面先上线，再慢慢补充，不要等资料全部齐了才发布。
- **一次只改一件事：** 跟 AI 说修改时，一次说清一两处，改完看效果再说下一处，比一次提十条更准确。
- **保留修改记录：** 每次满意了就在 GitHub Desktop 里 Commit 一次，改坏了能退回去。
- **定期更新内容：** 新产品、新案例、展会信息及时加上，让采购商看到你的最新动态。
- **对效果不满意：** 作者团队有专业美工，可以帮你优化设计，见[确定网站风格](03-style.md#想要更精致的设计找专业美工)。
