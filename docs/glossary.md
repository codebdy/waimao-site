# 网站常用术语速查

[← 返回首页](../README.md)

**这篇适合：** 跟 AI 说要改网站时，不知道某个位置或效果叫什么的人。不用背，用到时来查一下；叫不出名字也没关系，直接描述位置（比如“首页最上面那张大图”）或截图圈出来发给 AI，它一样能听懂。

## 一、页面的各个位置

| 术语 | 是什么 | 可以这样跟 AI 说 |
| --- | --- | --- |
| **页头 / 导航栏**（Header / Navbar） | 每页最上面一条，放 Logo、菜单和语言切换 | “导航栏加一个 Applications 菜单” |
| **菜单 / 下拉菜单** | 导航栏里的栏目链接；鼠标移上去展开的二级列表叫下拉菜单 | “Products 菜单下拉显示所有产品分类” |
| **首屏 / Hero 区** | 打开网页不用往下滑就能看到的第一块，通常是一张大图加一句主标题和按钮，决定访客对公司的第一印象 | “首屏标题改成 ‘Food Processing Machines’” |
| **Banner（横幅）** | 横跨整个页面宽度的大图或宣传条，常放在首屏或栏目页顶部。很多人把首屏大图也叫 Banner | “产品列表页顶部加一个 Banner 图” |
| **区块 / 板块**（Section） | 页面从上往下分成的一段一段，比如“产品分类”“为什么选择我们”“工厂实力” | “首页在产品分类下面加一个工厂实力区块” |
| **页脚**（Footer） | 每页最下面一块，放联系方式、快捷链接、版权信息 | “页脚加上 WhatsApp 号码” |
| **侧边栏**（Sidebar） | 正文旁边的一竖条，常放分类列表或联系方式 | “产品详情页右边加一个询价侧边栏” |
| **面包屑**（Breadcrumb） | 页面上方 “Home > Products > 清洗机” 这样的小路径，告诉访客现在在哪 | “产品页加面包屑导航” |
| **落地页**（Landing Page） | 专门为某个产品、展会或广告做的单独一页 | “为广州展会做一个落地页” |
| **404 页面** | 访问不存在的网址时显示的页面 | “404 页面加一个回到首页的按钮” |

## 二、页面上的小部件

| 术语 | 是什么 | 可以这样跟 AI 说 |
| --- | --- | --- |
| **按钮 / 行动按钮**（CTA） | 引导访客做下一步的按钮，比如 “Get a Quote”“Contact Us”。CTA 是 Call to Action 的缩写 | “首屏的按钮改成 Get a Quote，用橙色” |
| **卡片**（Card） | 一个个小方块，里面放图片、标题和简介，常用来排列产品或文章 | “产品卡片上显示型号和产能” |
| **图标**（Icon） | 小图形符号，比如电话、邮箱、齿轮图标 | “‘为什么选择我们’每一条前面加一个图标” |
| **标签页**（Tab） | 点不同的标题切换不同内容，比如产品页的“参数 / 应用 / 下载” | “产品详情用标签页分开参数和应用” |
| **折叠面板**（Accordion） | 点一下标题才展开内容，常用在常见问题 | “FAQ 做成折叠面板” |
| **弹窗**（Popup / Modal） | 盖在页面上方弹出来的小窗口 | “不要做进站就弹出的弹窗” |
| **悬浮按钮** | 固定在屏幕角落、页面滚动时也一直在的按钮，比如 WhatsApp 联系按钮 | “右下角加一个 WhatsApp 悬浮按钮” |
| **表单** | 让访客填写姓名、邮箱、需求的输入框组合，询盘表单就是一种 | “询盘表单加一个 ‘需求数量’ 字段” |
| **参数表** | 产品型号、尺寸、功率等规格排成的表格 | “产品页先放参数表” |
| **Cookie 同意框** | 欧美访客打开网站时，底部询问是否允许统计的提示条 | 见 [Cookie](cookie.md) |
| **网站小图标**（Favicon） | 浏览器标签页上网站名前面的小图标 | “把网站小图标换成我们的 Logo” |
| **分享预览图**（OG 图） | 把网址发到微信、WhatsApp、LinkedIn 时显示的那张预览图 | “把这张图设成分享图” |

## 三、图片和效果

| 术语 | 是什么 | 可以这样跟 AI 说 |
| --- | --- | --- |
| **轮播**（Carousel / Slider） | 几张图或几块内容在同一位置左右切换，可以点箭头或圆点翻页 | “首页做一个产品图片轮播，不要自动播放” |
| **动效 / 动画** | 网页元素动起来的效果，比如滚动到时淡入、鼠标移上去放大 | “产品卡片滚动到时淡入出现” |
| **滚动动效** | 往下滑页面时，内容依次浮现或移动 | “各区块滚动时轻轻上浮出现” |
| **悬停效果**（Hover） | 鼠标移到按钮或卡片上时的变化，比如变色、轻微放大 | “产品卡片鼠标移上去时图片轻微放大” |
| **视差**（Parallax） | 背景和前面内容滚动速度不同，产生立体纵深感 | “首屏背景做一点视差效果” |
| **灯箱**（Lightbox） | 点小图后放大全屏查看，可以左右翻 | “产品图片点了可以放大看” |
| **缩略图** | 大图的小尺寸预览，点了看大图 | “产品详情页主图下面放缩略图” |
| **场景图 / 氛围图** | 展示产品在使用环境中的图片，或营造感觉的背景图 | “首屏换成食品车间的场景图” |
| **示意图** | 用来说明原理或概念的图，不是产品实物照片 | “这张生成的图标注为示意图” |
| **配色 / 主色 / 强调色** | 网站用的一组颜色；主色是最多用的颜色，强调色用在按钮等重点处 | “主色用 Logo 的深绿，按钮用橙色” |
| **留白** | 内容之间空出的地方，留白够了页面显得高级、好读 | “首页区块之间留白多一点” |

## 四、网站和上线

| 术语 | 是什么 | 详细说明 |
| --- | --- | --- |
| **响应式** | 同一个网站在电脑、平板、手机上都自动排版好看 | 本 skill 做的网站默认就是响应式 |
| **本地预览** | 网站在你自己电脑上运行给你看，网址一般是 `localhost:4321`，别人看不到 | [预览和修改](04-preview.md) |
| **发布 / 部署 / 上线** | 把网站放到网上，别人能访问 | [Cloudflare](06-cloudflare.md) |
| **域名** | 网站的网址，比如 `www.yourcompany.com` | [域名](09-domain.md) |
| **SSL / https** | 网址以 https 开头，访问经过加密；证书有效、配置正确时，浏览器通常不会提示“不安全” | [域名](09-domain.md) |
| **仓库**（Repository） | 在 GitHub 上存放网站文件的地方，相当于网站的云端备份 | [GitHub](05-github.md) |
| **多语言** | 网站有英语、德语、西班牙语等多个版本，访客可以切换 | [开始建站](02-start.md) |
| **询盘** | 海外客户通过网站发来的询价或合作请求 | [询盘](inquiry.md) |
| **后台 / CMS** | 不改代码、在网页上登录就能改内容的管理系统，比如 RXCMS、WordPress | [开始建站](02-start.md) |
| **SEO** | 让网站更容易被 Google 搜到的优化工作 | [SEO](seo.md) |
| **收录 / 索引** | Google 把你的网页记进它的搜索库，记进去了才可能被搜到 | [SEO](seo.md) |
| **关键词** | 客户在 Google 上搜索时输入的词，比如 “vegetable washing machine” | [SEO](seo.md) |
| **网站地图**（Sitemap） | 列出希望被搜索引擎收录的页面网址，帮助 Google 发现这些页面 | [SEO](seo.md) |
| **访问统计**（Google Analytics） | 查看每天多少人来、从哪个国家来、看了哪些页面 | [Cookie](cookie.md) |

找不到你要的词？直接问 AI：“网站上 XX 这个东西叫什么？”，或者截图圈出来问它。
