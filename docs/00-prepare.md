# 开始前准备

[← 返回首页](../README.md) · 下一步：[安装](01-install.md)

开始之前，对照下面三张清单准备好。**不用一次全备齐**，标“现在”的先准备，其他用到时再弄。

## 账号

> 💡 **只需要一个谷歌账号。** 先准备一个谷歌账号，GitHub 和 Cloudflare 都可以直接用它登录，Vercel 再用 GitHub 账号登录，Google 的收录和统计工具本来就用它。只记一个账号和密码，最省事。

| 账号 | 用来做什么 | 什么时候要 |
| --- | --- | --- |
| AI 工具账号（Claude Code、Codex、WorkBuddy、DeepSeek Harness 选一个） | 帮你做网站 | 现在 |
| 谷歌账号（推荐） | 一个账号登录下面这些平台 | 现在 |
| 一个常用邮箱 | 接收客户询盘（可以就用谷歌邮箱） | 现在 |
| [GitHub](https://github.com/signup) | 保存网站代码，用谷歌账号登录 | 发布前 |
| [Cloudflare](https://dash.cloudflare.com/sign-up) | 把网站发布到网上（免费），用谷歌账号登录 | 发布前 |
| 域名（可选） | 用自己的网址 | 上线后 |

## 软件

| 软件 | 什么时候装 |
| --- | --- |
| 你选的 AI 工具 | 现在 |
| [Node.js 24 LTS](https://nodejs.org/en/download) | 现在 |
| [GitHub Desktop](https://desktop.github.com/) | 发布前 |

## 资料

- [ ] 公司名称和一句话介绍
- [ ] 主要产品、型号和参数
- [ ] Logo、产品照片、工厂照片
- [ ] 卖到哪些国家，网站要做哪些语言
- [ ] 接收询盘的邮箱
- [ ] 2 到 3 个你喜欢的网站（可选）

缺一些也能先开始，但上线前要换成真实资料。
