## 为什么不用买服务器：Serverless 部署的好处

网站发布在 Cloudflare 或 Vercel 这样的 Serverless 平台上，不用租服务器，也不用请人维护：

- **全球访问快**：网站通过全球边缘网络分发，欧美、中东、东南亚的客户打开通常更快
- **零运维**：不用自己给服务器装系统、打补丁，这些由平台负责
- **自带 SSL 证书**：自动启用 https，不用自己买证书、续证书
- **不怕访问量突增**：展会、广告带来大量访问时，平台自动扩容（在套餐额度内）
- **更安全**：纯静态网站没有数据库和后台登录口，少了很多常见的被入侵途径
- **费用低**：Cloudflare 免费版就够起步，按需再升级
- **改完自动上线**：推送到 GitHub 后平台自动构建，成功后网站随之更新
