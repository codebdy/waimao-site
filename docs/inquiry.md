# 询盘表单

[← 返回首页](../README.md) · 相关：[RXCMS 站](content-rxcms.md)

**这篇适合：** 想让客户直接在网站上填表发询盘的人。

## 两种联系方式

| | 邮件链接（默认） | 站内询盘表单 |
| --- | --- | --- |
| 客户怎么做 | 点按钮，打开他自己的邮件软件写信 | 在网页上填姓名、邮箱、需求，点提交 |
| 需要什么 | 只要一个询盘邮箱 | 需要开通 RXCMS 询盘服务 + Cloudflare 人机验证 |
| 询盘存在哪 | 你的邮箱 | RXCMS 后台，同时发邮件通知你 |
| 优点 | 简单，零成本 | 客户操作方便，询盘有记录、不会漏 |

刚开始用邮件链接完全够用。告诉 AI 你的询盘邮箱就行。

## 站内表单需要准备什么

1. **开通 RXCMS 询盘服务**：联系作者开通，会拿到服务地址和询盘用的密钥。
2. **注册 Cloudflare Turnstile**（免费的人机验证，用来挡机器人）：在 Cloudflare 控制台找到 **Turnstile**，添加一个站点，填你网站的域名，会得到一个“站点密钥”和一个“私密密钥”。[官方说明](https://developers.cloudflare.com/turnstile/get-started/)
3. 网站已经确定发布到 Vercel 还是 Cloudflare。

然后告诉 AI：

```text
我要在网站上加询盘表单，已经开通 RXCMS 询盘和 Turnstile，请帮我设置，并告诉我哪些要填到发布平台。
```

AI 会改好网站，并列出需要你在 Vercel 或 Cloudflare 环境变量里填的几项。**私密密钥只填在平台里，不要发到聊天框。**

## 表单怎么防垃圾询盘

已经自带三道防线，不用另外设置：

- **隐藏陷阱**：表单里有一个真人看不见的输入框，机器人填了就直接拒收
- **人机验证**：Cloudflare Turnstile 在服务器端核对，机器人很难绕过
- **来源检查**：只接受从你自己网站发出的提交

客户提交的内容通过 HTTPS 加密传输，询盘密钥只在服务器端，浏览器里拿不到。

## “提交成功”是什么意思

客户提交后看到 “Your inquiry has been received”，表示**询盘已经保存到 RXCMS 后台**。

但**保存成功不等于你一定收到了邮件通知**：邮件可能进了垃圾箱，或者邮件设置有问题。所以：

- 定期登录 RXCMS 后台看询盘列表，这里最全
- 第一次上线后自己提交一条测试询盘，确认后台有记录、邮箱也收到了
- 被系统判为垃圾的询盘也会保存在后台，只是不发邮件通知，偶尔去看一眼

## 完成标志

自己在网站上提交一条测试询盘：后台能看到这条记录，你的邮箱也收到了通知。

## 常见问题

- **点提交没反应或报错？** 检查平台里的环境变量是否都填了；用的是 Cloudflare 的话，是不是用“拖拽上传”发布的（那样表单不工作，要用连接 GitHub 的方式）。
- **在平台送的网址上表单不能用，换成正式域名就好了？** Turnstile 和表单只允许你设置过的域名，测试网址也要加进去，让 AI 帮你调整。
- **后台有询盘，邮箱没收到？** 先查垃圾邮件箱，再联系作者确认通知邮箱设置。
