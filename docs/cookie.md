# Cookie 同意框和 Google 统计

[← 返回首页](../README.md)

**这篇适合：** 想知道网站底部弹出的隐私框是什么、要不要开、怎么接 Google 统计的人。

## 它是什么

访客第一次打开网站时，角落会弹出一个框，让访客选择**是否允许统计访问数据、是否允许广告相关的追踪**。

欧洲等地区对网站收集访客数据有严格要求，外贸网站的客户大量来自这些地区，所以建议保留。

它**不是**让访客给 Google 评分，也不是问卷。

## 默认是什么状态

- 同意框：**开启**
- Google 统计、Google 广告：**都没接**，不会向 Google 发送任何数据

也就是说，默认情况下只记住访客“选了什么”，没有任何追踪。

## 想看网站访问数据：接 Google Analytics

1. 打开 [Google Analytics](https://analytics.google.com/)，用 Google 账号创建一个“媒体资源”，选网站，填你的域名。
2. 创建完会得到一个以 **G-** 开头的“衡量 ID”，比如 `G-ABC123XYZ`。
3. 告诉 AI：“Google Analytics 的 ID 是 G-ABC123XYZ，请帮我接上。”
4. Commit、Push 发布。

这个 ID 是公开的，可以发给 AI，不是密码。

**效果：** 只有点了“接受”的访客才会被统计；拒绝的访客不会。所以统计到的人数会比实际少，这是正常的。

在投 Google 广告的话，同样把以 **AW-** 开头的广告 ID 告诉 AI。

## 访客怎么改变主意

网站页脚有 **Cookie settings** 按钮，访客随时可以点开重新选择。撤回同意后页面会刷新一次，之后就不再统计。

## 想关掉同意框

如果你不需要任何统计和广告追踪，可以告诉 AI：“关掉 Cookie 同意框”。

**注意：** 关掉同意框的同时，Google 统计和广告也会一起关闭。这是为了避免出现“没问访客就偷偷追踪”的情况。

## 改完怎么测试

用浏览器的**无痕窗口**打开网站，就能像新访客一样看到弹框。普通窗口里已经选过一次，就不会再弹了。

## 需要知道的

- 网站的隐私页（Privacy）是模板，**上线前要按你公司的实际情况补充**，可以让 AI 帮你起草，你来确认。
- 这个同意框不是 Google 认证的专业产品，也不能保证满足所有国家的法律要求。生意主要在欧盟、对合规要求高的，建议咨询专业人士。
- 你自己另外加的聊天插件、Facebook 像素等，不会被这个同意框自动管理，加之前先问 AI。
